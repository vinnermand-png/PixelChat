# Pixel Campfire Chat

Build “Pixel Chat” — a 100% pixel-art social chat world.

Create one small isometric pixel map with a dark snowy ground, trees, a cabin and a central campfire.

The user controls a pixel avatar by clicking to move. Add a username above the avatar and several demo avatars around the map.

Create a pixel-style global chat at the bottom where messages also appear as speech bubbles above the player.

The entire UI must be pixel art: pixel font, sharp edges, no gradients, no modern cards, no glassmorphism.

Make it feel like a retro online game, not a normal website.
